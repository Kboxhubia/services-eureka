# MetaDoinGO
Estos son los repositorios creados por el Ing. Jorge Huerta para respaldar el Proyecto MetaDoinGO. 
Framework de meta-autonomo para Desarrollo de Ideas, Arquitecto de Soluciones, Automatización, Ingeniería de Prompts/BluePrint, Creación de Skills/Loops/MDBLU. Creación de Agentes IA autónomos aplicados a Ideas, servicios, procesos o situaciones o problemas para transformarlas en @Soluciones y/o aplicarlas en @Soluciones finalmente exponerla a la base de conocimiento de MetaDoinGO y crear el documento publico de propiedad intelectual para publicarlo en Internet 100% Autónomo. 
Un modelo puede usar El 80% se Automatiza y solo el 20% se piensa o se analiza, tu crees que solo es automatizar, el tiempo de análisis se redefine entre un % mayor o menor, según el caso de Paradigma o antiparadigma eso es MetaDoinGO. Si creamos varios modelos del caso son varios tiempos con resultados complementamente distintos separamos la respuesta determinística para alcanzar y consolidar la particularidad de la Meta Do "...", la Meta In "...+..." y Meta GO (.+.). 
El mejor modelo no es el mas rápido o el mas lento, es quien coteje mejor el razonamiento dividos en la cantidad de tokenes usados "...", si tu problema es el tiempo ..., ya tienes un problema que no lo vas a resolver con un prompt de AI, sino con Metas separadas en DoinGo com un billon de tokens disponibles.
